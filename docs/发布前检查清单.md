# 发布前检查清单

> 目的：**做出来的安装包里，绝对不能带着你自己在用的代理**。
> 订阅地址里带 token（访问令牌），发出去等于把账号公开；节点缓存同理。
> 本文按顺序做完，再打包。

---

## 一、为什么必须单独做一遍

三个地方会「顺手」把你自己的代理带出去：

| 位置 | 会带出去什么 | 为什么危险 |
|---|---|---|
| `D:\AppProxy\data\lines.json` | 订阅地址（含 token）、线路名 | 别人能直接拿去用、看余额 |
| `D:\AppProxy\data\nodes-*.json` | 节点服务器地址、uuid/密码 | 等于把节点白送 |
| `D:\AppProxy\data\runtime\*.json` | 生成的 sing-box 配置（同样含节点） | 同上 |

代码目录里不含这些 —— 但要**验证**，不能假设。

---

## 二、逐条执行

### 1. 预演，先看清楚要删什么

```bat
cd /d <项目目录>
python -m appproxy.cli cleanup
```

预期输出会列出你现有的每一条线路及其订阅地址。一条都没列出来，说明已经清过了。

### 2. 真删（自动先备份）

```bat
python -m appproxy.cli cleanup --yes
```

它会：

- 备份 `lines.json` + `profiles.json` → `D:\AppProxy\backup-cleanup-<时间>\`
- 删掉所有线路、节点快照、生成的配置、生成的快捷方式
- 把档案的线路绑定改成「直连」（档案本身保留）

### 3. 确认 TUN 提权任务也清掉

```bat
python -m appproxy.cli tun remove
```

任务是 `AppProxyTun`，也可以在「任务计划程序」里手动删。

### 4. 验证：全项目目录里搜不到你的订阅痕迹

```bat
:: 把下面三条换成你自己的订阅域名 / 线路名 / token 片段
findstr /S /I /M "<你的订阅域名>" *.*
findstr /S /I /M "<你的线路名>"   *.*
findstr /S /I /M "token="        *.*
```

同时确认运行数据目录是空的：

```bat
dir D:\AppProxy\data
:: 期望：没有 lines.json 里的线路、没有 nodes-*.json、runtime 里没有 *.json
```

### 5. 确认图标与快捷方式里的残留

```bat
dir D:\AppProxy\shortcuts
dir D:\AppProxy\icons
```

`shortcuts\*.lnk` 已被 cleanup 删除；`icons` 里的图标本身不含代理信息，可以留 ——
但如果角标上还写着某条线路的短码，就整个删掉重建。

### 6. 打包时只带这三样

| 打进去 | 不带 |
|---|---|
| `appproxy\`（Python 代码） | `D:\AppProxy\`（运行数据，整目录） |
| `third_party\`（sing-box 内核 + LICENSE） | `backup-*` 备份目录 |
| 启动脚本 / 主界面入口 | 你自己截的实机图（含订阅地址） |

### 7. 干净环境装一次

在**另一个 Windows 账户**（或一台新虚拟机）里装，然后：

1. 打开主界面 → 应该看到**接线引导页**（`docs/引导页.png`），而不是列表；
2. 不填任何东西，直接看「设置 → 线路」：**应该是空的**；
3. 点「开启 TUN」→ 应该**自己弹出「用户账户控制」**（说明提权任务没被打包带走，这是对的），
   点「是」之后内核起来；再点一次「开启 TUN」不应再弹窗（任务已装）。

### 8. 最后一遍：截图里有没有贴订阅地址

README、发布说明、群公告里所有出现订阅地址的地方都要打码。

最省事的做法是**别用真实线路截图**：

```bat
python tests\make_demo_home.py
set APPPROXY_HOME=D:\AppProxy-demo
set APPPROXY_SHOT_CLEAN=1
python tests\live_view.py --shot
python tests\make_tray_sheet.py
python tests\make_icon_sheet.py
```

`make_demo_home.py` 会造一套假线路（`example.com` 订阅 + RFC 5737 文档保留地址），
出来的图可以放心贴到任何地方。

## 三、一次性记住的三条

1. **运行数据永远不进安装包**：代码在项目目录，数据在 `D:\AppProxy`，物理分开就是为这个。
2. **任何带 token 的地址不写进文档**：README 里只写「订阅地址」四个字。
3. **打包前跑一次 `cleanup --yes`**，哪怕你确定什么都没改 —— 成本 5 秒。
